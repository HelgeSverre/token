Agent identity treatments

Three ways to identify a coding agent in the session list and transcript. Each keeps the agent’s mark small enough that the work remains the primary visual signal.

This is a design comparison, not a production asset bundle. The marks are live from the ACP Registry, are not copied into this repository, and should only appear once the archive’s provider is confidently mapped. “Unknown” deliberately has a plain white fallback.

Source and use constraints

The ACP Registry lists an icon URL for all three mapped agents and recommends a 16 × 16 icon.svg. This prototype renders those URLs as CSS masks so the exact registry geometry is used; it does not download, alter, or commit the assets. The listed package licenses do not by themselves grant trademark rights to the associated company logos.
