Token · Command Palette & Overlay Mockups

Design spike for a visually stronger palette/overlay system, plus the surfaces the LSP integration (diagnostics, hover, completion, code actions, problems panel) will need. All mockups use the real default-dark theme values and JetBrains Mono 14px — what you see is what the softbuffer painter would draw.

Everything below uses only primitives the renderer already has or can trivially add: filled rects, 1px borders, alpha blending, rounded corners (small radius fills), and text. Backdrop blur (mockup A4) is the one exception — flagged where used.
