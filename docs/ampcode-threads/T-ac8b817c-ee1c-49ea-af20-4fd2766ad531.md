   - `move_cursor_word_left()` and `move_cursor_word_right()` in update.rs
   - How they scale with line length

   - Operations in `update_document()` that iterate over cursors
   - `cursors_in_reverse_order()` pattern
   - Selection deletion with multiple cursors

4. **Buffer Operations:**
   - `insert`, `remove` on Rope
   - `slice` operations for copy/paste

5. **Undo/Redo Operations:**
   - `EditOperation` enum handling
