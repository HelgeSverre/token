I implemented file operations for a Rust text editor following the Elm Architecture (Message → Update → Command → Render).

What I completed:
- Phase 1: Refactored AppModel::new() with ViewportGeometry, load_config_and_theme(), create_initial_session() helpers
- Phase 2: Native file dialogs via rfd crate (⌘O Open File, ⇧⌘O Open Folder, ⇧⌘S Save As)
- Phase 4: File validation in src/util/file_validation.rs with FileOpenError enum, validate_file_for_opening(), is_likely_binary()
- Added workspace_root: Option<PathBuf> to AppModel for future workspace support

What remains (documented in docs/feature/file-operations.md):
- Phase 3: Visual feedback for file dropping (hover overlay) - need DropState in UiState, DropMsg message type, handle WindowEvent::HoveredFile/HoveredFileCancelled, render overlay
- Phase 5: CLI arguments with clap - need CliArgs struct with --new, --wait, --line, --column flags, StartupConfig enum
- Duplicate file detection (already-open files) - not yet started

Architecture patterns I established:
- New Cmd variants for side effects (ShowOpenFileDialog, ShowSaveFileDialog, ShowOpenFolderDialog)
- New AppMsg variants for dialog results (OpenFileDialogResult, SaveFileAsDialogResult, OpenFolderDialogResult)
- Commands run in background threads via std::thread::spawn, send results back via msg_tx channel
- Keymap commands added to src/keymap/command.rs with to_msgs() mapping
- Keybindings added to both keymap.yaml and src/keymap/defaults.rs

File validation approach:
- validate_file_for_opening() checks existence, permissions, 50MB size limit
- is_likely_binary() scans first 8KB for null bytes
- Integrated into open_file_in_new_tab() in src/update/layout.rs and create_initial_session() in src/model/mod.rs

I prefer XDG-style ~/.config paths over platform-native locations like ~/Library/Application Support on macOS.

The util module was reorganized from src/util.rs to src/util/ directory with text.rs and file_validation.rs submodules.

next lets focus on cli arguments, duplicate file detection and visual feedback during file drag-hover
