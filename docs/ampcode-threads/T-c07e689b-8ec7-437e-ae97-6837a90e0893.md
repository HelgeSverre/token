Your CI builds for 4 targets. Here's how to set up local cross-compilation on your Mac:

### Cross-Compilation Setup

**1. Add the targets:**
```bash
rustup target add x86_64-apple-darwin aarch64-apple-darwin x86_64-unknown-linux-gnu x86_64-pc-windows-msvc
```

**2. For Linux builds, install [cross](https://github.com/cross-rs/cross):**
```bash
cargo install cross --git https://github.com/cross-rs/cross
```
Cross uses Docker to build Linux targets on macOS.

**3. For Windows builds, use [cargo-xwin](https://github.com/rust-cross/cargo-xwin):**
```bash
cargo install cargo-xwin
```

**Build commands:**
```bash
## macOS targets (native, no extra setup)
cargo build --release --target x86_64-apple-darwin
cargo build --release --target aarch64-apple-darwin

## Linux (via cross + Docker)
cross build --release --target x86_64-unknown-linux-gnu

## Windows (via xwin)
cargo xwin build --release --target x86_64-pc-windows-msvc
```
