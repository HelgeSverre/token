- Added clap dependency with derive feature
- Created src/cli.rs with CliArgs struct supporting --new, --wait, --line, --column flags
- StartupConfig and StartupMode enums organize startup behavior
- Line/column flags are 1-indexed from user, converted to 0-indexed internally
- 7 unit tests for CLI parsing

2. Duplicate File Detection:
- Added find_open_file() and is_file_open() methods to EditorArea
- Uses canonicalized paths to handle symlinks/relative paths
- Integrated into open_file_in_new_tab() - focuses existing tab instead of creating duplicate
- Status bar shows "Switched to: filename"

3. Visual Feedback for File Drag-Hover (Phase 3):
- Added DropState struct to UiState with hovered_files and is_hovering fields
- Added FileHovered and FileHoverCancelled messages to UiMsg
- Handle WindowEvent::HoveredFile and HoveredFileCancelled in runtime
- Render semi-transparent drop overlay centered in window with "Drop to open: filename" text

The editor follows Elm Architecture (Message → Update → Command → Render). I prefer XDG-style ~/.config paths.

All builds pass, lint passes, and 703 tests pass.
