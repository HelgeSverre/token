# Fix cursor calls in input.rs

## User

Fix all cursor()/cursor_mut()/selection()/selection_mut() calls in src/input.rs after they were renamed to primary_cursor()/primary_cursor_mut()/primary_selection()/primary_selection_mut().

Context: This is part of a multi-cursor refactor. In input.rs, these are mostly for arrow key navigation that checks selection state before moving.

Classification:
1. For arrow keys checking selection → use active_selection() since this should work with the focused cursor
2. For cursor movement after selection check → use active_cursor_mut()
3. If the code path explicitly handles multi-cursor differently, check has_multiple_cursors() first

The editor has these methods available:
- active_cursor() / active_cursor_mut()
- active_selection() / active_selection_mut()
- primary_cursor() / primary_cursor_mut()
- primary_selection() / primary_selection_mut()
- has_multiple_cursors()
