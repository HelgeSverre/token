Context: This is part of a multi-cursor refactor.

Classification:
1. Status bar / UI display → use active_cursor() / active_selection()
2. View rendering for line highlight → use active_cursor()
3. App reset/initialization → use primary_cursor_mut()

- active_cursor() / active_cursor_mut()
- active_selection() / active_selection_mut()
