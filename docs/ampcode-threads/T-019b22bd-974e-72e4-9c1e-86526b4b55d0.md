## Key Architectural Patterns

### 1. **State Machine for CSV Parsing**
- Handles quoted fields spanning multiple lines
- Minimal memory overhead for streaming

### 2. **Delimited String Storage**
- Single `std::vector<std::string>` instead of vector-of-vectors
- Uses invalid UTF-8 byte (`0xFA`) as field delimiter
- Efficient for large datasets

### 3. **Lazy Cell Editing**
- Single overlay input widget repositioned for each cell
- No per-cell widgets (memory efficient)
- Overlay resized on viewport changes

### 4. **Undo Snapshots**
- Full table snapshots for structural changes
- Single-cell backups for edits
- Tracks selection state for redo

### 5. **Encoding Detection**
- Multi-pass heuristic (BOM → encoding type → delimiter)
- Confidence scoring with user fallback
- Supports 5 encodings + UTF-16/32 variants

---

## Recommendations for Rust Implementation

1. **Data Model**: Replicate the delimited-string storage design - use a `Vec<String>` with a special delimiter byte
2. **Parsing**: Implement similar FSM-based parser with stateful handling for quoted fields
3. **Rendering**: Use virtual viewport (render only visible cells) for Elm/web rendering
4. **Memory**: Avoid per-cell allocations - reuse buffers like FLTK's multiline input approach
5. **Undo**: Implement differential snapshots - full table on structural changes, cell-only on edits
6. **Scrolling**: Implement lazy loading if dealing with truly massive files (100M+ rows)
7. **Encoding**: Prioritize UTF-8, but support legacy formats via encoding detection heuristics

Parsing Strategy\n\n### 5.1 Initial Parse (Streaming)\n\n```rust\nuse csv::{ReaderBuilder, Terminator};\n\n/// Parse result with potential warnings\npub struct ParseResult {\n    pub data: CsvData,\n    pub warnings: Vec<ParseWarning>,\n}\n\npub enum ParseWarning {\n    /// Rows have different column counts\n    InconsistentColumns { expected: usize, found: usize, row: usize },\n    /// Truncated due to size limit\n    Truncated { max_rows: usize },\n    /// Invalid UTF-8 replaced\n    InvalidUtf8 { row: usize },\n}\n\n/// Parse CSV from document buffer\npub fn parse_csv(\n    source: &str,\n    delimiter: u8,\n    max_rows: Option<usize>,\n) -> Result<ParseResult, CsvParseError> {\n    let mut reader = ReaderBuilder::new()\n        .delimiter(delimiter)\n        .has_headers(false)\n        .flexible(true) // Allow varying column counts\n        .from_reader(source.as_bytes());\n    \n    let mut rows: Vec<String> = Vec::new();\n    let mut max_cols = 0;\n    let mut warnings = Vec::new();\n    \n    for (row_idx, result) in reader.records().enumerate() {\n        // Check row limit\n        if let Some(max) = max_rows {\n            if row_idx >= max {\n                warnings.push(ParseWarning::Truncated { max_rows: max });\n                break;\n            }\n        }\n        \n        match result {\n            Ok(record) => {\n                let col_count = record.len();\n                \n                // Track column count variance\n                if row_idx > 0 && col_count != max_cols {\n                    warnings.push(ParseWarning::InconsistentColumns {\n                        expected: max_cols,\n                        found: col_count,\n                        row: row_idx,\n                    });\n                }\n                max_cols = max_cols.max(col_count);\n                \n                // Convert to delimited string\n                let row_str = record\n                    .iter()\n                    .collect::<Vec<_>>()\n                    .join(&char::from(CsvData::FIELD_DELIMITER).to_string());\n                \n                rows.push(row_str);\n            }\n            Err(e) => {\n                // Log but continue (flexible parsing)\n                tracing::warn!(\"CSV parse error at row {}: {}\", row_idx, e);\n                rows.push(String::new());\n            }\n        }\n    }\n    \n    Ok(ParseResult {\n        data: CsvData {\n            rows,\n            field_delimiter: CsvData::FIELD_DELIMITER,\n            column_count: max_cols,\n            parsed_revision: 0,\n        },\n        warnings,\n    })\n}\n```\n\n### 5.2 Delimiter Detection\n\n```rust\n/// Detect delimiter by sampling first few lines\npub fn detect_delimiter(source: &str) -> u8 {\n    const CANDIDATES: &[u8] = &[b',', b'\\t', b';', b'|'];\n    const SAMPLE_LINES: usize = 5;\n    \n    let lines: Vec<&str> = source.lines().take(SAMPLE_LINES).collect();\n    if lines.is_empty() {\n        return b','; // Default\n    }\n    \n    let mut scores: Vec<(u8, f64)> = CANDIDATES\n        .iter()\n        .map(|&delim| {\n            let counts: Vec<usize> = lines\n                .iter()\n                .map(|line| line.bytes().filter(|&b| b == delim).count())\n                .collect();\n            \n            // Score: consistency (low variance) + presence (count > 0)\n            let mean = counts.iter().sum::<usize>() as f64 / counts.len() as f64;\n            if mean == 0.0 {\n                return (delim, 0.0);\n            }\n            \n            let variance = counts.iter()\n                .map(|&c| (c as f64 - mean).powi(2))\n                .sum::<f64>() / counts.len() as f64;\n            \n            // Higher score = better (high count, low variance)\n            let consistency = if variance == 0.0 { 1.0 } else { 1.0 / (1.0 + variance) };\n            (delim, mean * consistency)\n        })\n        .collect();\n    \n    scores.sort_by(|a, b| b.1.partial_cmp(&a.1).unwrap_or(std::cmp::Ordering::Equal));\n    \n    scores.first().map(|(d, _)| *d).unwrap_or(b',')\n}\n```\n\n### 5.3 Incremental Re-parse (Phase 2+)\n\nFor editing, we need to detect which rows changed:\n\n```rust\n/// Track what changed between parses\npub struct CsvDiff {\n Replace the range with the new value (properly escaped)\n    let escaped_value = escape_csv_value(&edit.new_value, csv.delimiter);\n    \n    // 3. Apply edit to document\n    let start_offset = cell_range.start;\n    let end_offset = cell_range.end;\n    \n    // Delete old content\n    document.buffer.remove(start_offset..end_offset);\n    \n    // Insert new content\n    document.buffer.insert(start_offset, &escaped_value);\n    \n    // Mark as modified\n    document.is_modified = true;\n    document.revision = document.revision.wrapping_add(1);\n    \n    Ok(())\n}\n\n/// Find byte range of a cell in the document\nfn find_cell_range(\n    document: &Document,\n    csv: &CsvState,\n    pos: CellPosition,\n)
