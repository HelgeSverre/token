# What is saturating_add

## User

what is saturating_add

## Assistant

`saturating_add` is a Rust integer method that adds two numbers but **clamps at the numeric bounds** instead of overflowing/wrapping.

```rust
let x: u8 = 250;
x.saturating_add(10)  // Returns 255 (max u8), not 4 (wrapped)
```

Useful for avoiding overflow panics in debug mode or unexpected wraparound in release mode.
